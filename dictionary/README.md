# Dictionary

The dictionary contains canonical definitions for concepts, terms, and primitives used throughout REDE-Disclosure.

## Purpose

Each file in this directory is a **concept** artifact — a precise, authoritative definition of a single term. Concepts are the atomic units of the knowledge system. Articles in the encyclopedia and structured discussions build on top of them.

## Artifact Type

`type: concept`

## Contributing

See the [concept issue template](../.github/ISSUE_TEMPLATE/concept.md) to propose a new concept, and the [concept template](../templates/concept.md) to draft the artifact itself.

## Conventions

- One concept per file
- Filename matches the artifact `id` (e.g., `causal-chain.md`)
- All cross-references use artifact `id` values, not file paths
