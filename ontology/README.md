# Ontology

This directory contains formal ontology declarations and mappings that define the structural relationships between concepts in REDE-Disclosure.

## Purpose

The ontology layer makes the knowledge base machine-readable and formally reasoned. It declares class hierarchies, property definitions, and equivalences or mappings between REDE concepts and external ontologies.

## Artifact Type

`type: ontology`

## Contributing

Propose ontology changes via a GitHub Issue before drafting. Ontology artifacts have higher review requirements due to their structural impact on the rest of the knowledge base.

## Conventions

- One ontology declaration per file
- Filename matches the artifact `id`
- Mappings to external ontologies must cite the source ontology URI
