# The History That History Forgot

A relational anchor for the next generation of the REDE parser.

The historical narrative is working material for examining relationships among language, intent, authority, provenance, transformations, and the preservation or loss of meaning. It does not prescribe a conclusion.

## Organization

- `The_History_That_History_Forgot.md` — evolving narrative (to be added from the ChatGPT Library document)
- `provenance/` — witnesses, references, and source relationships
- `transforms/` — operator mappings and parsing investigations
- `artifacts/` — related research artifacts

This anchor is part of the broader `Relational-Anchors` collection in REDE-Disclosure.
