# Discussions

This directory contains structured discussion artifacts — records of deliberation, debate, and resolution that inform knowledge artifacts.

## Purpose

Structured discussions capture the reasoning behind decisions. They preserve the arguments considered, the evidence examined, and the outcome reached, so the knowledge base is not just a collection of conclusions but a traceable record of how those conclusions were reached.

## Artifact Type

`type: discussion`

## Contributing

See the [discussion issue template](../.github/ISSUE_TEMPLATE/discussion.md) to open a discussion, and the [discussion template](../templates/discussion.md) to draft the artifact.

## Conventions

- One discussion per file
- Filename matches the artifact `id`
- Discussions that reach resolution must record the outcome in the `resolution` frontmatter field
- Unresolved discussions remain in `status: draft`
