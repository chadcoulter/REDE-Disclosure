# Encyclopedia

The encyclopedia contains long-form articles that develop, contextualize, and interconnect concepts from the dictionary.

## Purpose

Where the dictionary defines individual terms, the encyclopedia synthesizes them. Articles explain how concepts relate, trace the history of ideas, and provide the depth needed to reason about complex topics in REDE-Disclosure.

## Artifact Type

`type: article`

## Contributing

See the [article issue template](../.github/ISSUE_TEMPLATE/article.md) to propose a new article, and the [article template](../templates/article.md) to draft the artifact itself.

## Conventions

- One article per file
- Filename matches the artifact `id` (e.g., `rede-transform-overview.md`)
- Articles must reference at least one concept by `id`
- Substantive claims should be sourced in the frontmatter
