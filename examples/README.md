# Examples

This directory contains worked examples demonstrating how to create and use REDE-Disclosure artifacts.

## Purpose

Examples help new contributors understand the artifact format in practice. Each example is a complete, well-formed artifact that also serves as a reference implementation.

## Contributing

Examples should be minimal, clear, and complete. They must use realistic (not placeholder) content so contributors understand what good artifacts look like. Each example should demonstrate at least one non-obvious aspect of the artifact format.

## Conventions

- Filename matches the artifact `id`
- Examples use `status: stable` only if they have passed full review
- New examples should start at `status: draft`
