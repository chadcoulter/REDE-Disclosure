# Templates

This directory contains canonical templates for each artifact type in REDE-Disclosure.

## Available Templates

| Template | Artifact Type | Target Directory |
|---|---|---|
| [concept.md](concept.md) | `concept` | `dictionary/` |
| [article.md](article.md) | `article` | `encyclopedia/` |
| [discussion.md](discussion.md) | `discussion` | `discussions/` |
| [ontology.md](ontology.md) | `ontology` | `ontology/` |

## Usage

1. Copy the appropriate template into the target directory.
2. Rename it to match your intended artifact `id` (e.g., `causal-chain.md`).
3. Fill in all required frontmatter fields.
4. Write the body content.
5. Set `status: draft`.
6. Open a pull request following the process in [CONTRIBUTING.md](../CONTRIBUTING.md).
